# 《源石与神灵》

小说简介：

我时常想——祂的视界是怎样呢？

我们的喜怒哀乐，在祂看来又如何？

后来我想明白了。

--------------

良善的夫子阿丽娜向神明许愿：“坚实的牧者，全知全能的神！愿人都尊你的名为圣。愿你的国降临；愿你的旨意行在地上，如同行在天上。我知道我若叩门，你就开门；我祇要求，你就会应。虔诚的羔羊阿丽娜向你祈祷——愿泰拉不再起刀兵，百姓不再饥饿穷苦，愿感染者与非感染者摒弃偏见。阿门！”

于是祂应了这约，启示道：【你们的死临到头了。】

圣典新约的福音落下帷幕，末日预言的原罪开始清算。

祂非良善的神。凡是见到龌龊的，祂就欢喜；凡是听到残暴的，祂便快活——因为只有最恶最烂的，才能登上明日的诺亚！
