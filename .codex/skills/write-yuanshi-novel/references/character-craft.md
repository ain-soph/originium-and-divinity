# 人物塑造方法

## 目标

用稳定欲望在不同压力下作出的选择塑造人物。人物可以真诚、残酷、自利、体贴和自欺同时成立，不必被归纳成单一形容词。

## 人物建模

为重要人物分别记录：

1. 她公开宣称自己要什么。
2. 她实际不能放弃什么。
3. 她需要相信自己是怎样的人。
4. 她受到哪些制度、知识和身体条件约束。
5. 她愿意让谁承担什么代价。
6. 当价值与欲望冲突时，她最终选择哪一边。

人物核心通常位于第3项与第5项之间，而不在人物自我介绍里。

群体角色也要接受同样检查：它是否拥有可辨认的共同欲望、选择、内部差异或足以改变权力关系的行动。若一个群体只能搬运、护送、断后并按计划团灭，所有情节功能都可由现有人物或劳动者完成，就删除它；不要为了保住一句致敬台词或一次牺牲，再换名制造另一批无名尸体。

## 并存动机

- 不用后发现的私欲取消先前的真情。阿丽娜真心爱塔露拉、希望村民得救，同时通过牺牲自己完成救世主式非凡。
- 不把贡献当作免责。凯尔希真实救过世界，也真实地用救世功绩证明自己不可牺牲。
- 不把清醒承担当作善。科西切理解命运后接受死亡，使他复杂，却不洗白其统治。
- 写清动机之间如何共同生成同一个动作，避免“表面为别人，实际只为自己”的廉价翻转。

## 人物对照

建立对照时比较以下五项：

| 项目 | 人物甲 | 人物乙 |
| --- | --- | --- |
| 共同事实 | 看见了什么 | 看见了什么 |
| 保留前提 | 什么不可被推翻 | 什么不可被推翻 |
| 自我叙事 | 必须相信自己是谁 | 必须相信自己是谁 |
| 最终选择 | 做了什么 | 做了什么 |
| 代价归属 | 谁付出 | 谁付出 |

- 能天使与莫斯提马：共同看见莉夏不传福音，分别保留神的真实性与教义。
- 阿丽娜与凯尔希：共享救世主自我叙事，分别通过死亡与拒绝死亡确认非凡。
- 凯尔希与能天使：一人要求别人承担后拒绝牺牲，一人理解无奖赏后亲自进入祭品位置。

对照不要求人物见面。跨卷结构对照可以由相似选择、相反代价和同一意象完成。

## 人物弧

- 让稳定欲望升级，不靠突然更换人格。生前阿丽娜以“村子的羔羊”追求非凡；她死后由神／父站回阿丽娜位置，已经发生本体层面的主体变化，不能再把神自称神当作同一人欲望升级的证据。
- 每次关键事件剥除一种自我安慰。能天使依次失去天堂、福音和神必良善的保证，剩下不以奖赏为条件的信仰。
- 让终局选择回收早期的小动作或误读。奶奶之死的错误解释成为阿丽娜后来献身的训练样本。
- 允许人物保留同一句论证，只改变自己在论证中的位置和代价归属。凯尔希若始终坚持“生命属于公共事业”，这句话既能要求他人牺牲，也能被她用来证明自己必须活着；腐化由适用对象显现，不必靠观点突然翻转。
- 动态人物不必不断更换信念。可以让一系列稳定人物或事件逐项封死她原有的自我安慰，使最终选择成为排除后的结果。
- 人物弧必须经过可见选择；知道更多设定不等于人物已经改变。

## 人物关系

- 用物件流转、身份承担和实际代价表现关系。传单被抽走、保存、呈证、冒认，比直接命名“情书”拥有更多关系信息。
- 爱情可以明确存在，但正文无需用类型标签反复说明。
- 关系中的安慰可以在事实层为假。“一定是的”不是共同相信，而是塔露拉明知不实仍维护阿丽娜赖以承受死亡的解释。
- 区分占有一个人的死亡意义、爱一个人、替她承担罪责和拥有她的身份；这些可以交叠，但不能互相替代。

## 自我认知与世界事实

- 分开记录三层：人物怎样理解自己、其他人物怎样判断她、世界规则实际允许什么。
- 人物说“我是神”首先是人物行为，不自动升级为设定。
- 生前有限阿丽娜不是神；1-6后以阿丽娜身份站立和说话的主体就是神／父。若塔露拉仍坚持把眼前者当作只属于自己的有限恋人，这才是需要通过关系行为表现的身份误认。
- 身份重叠不能取消责任。神可以采用塔露拉的身份，不等于塔露拉的选择都可归罪于神。

## 对话塑造

- 让人物用职业职责、熟悉教义和当下需求说话，不让所有人共享作者术语。
- 军官只说目标、命令、批准和报告；生物学映射由结构显现。
- 莫斯提马用“真神应传福音”判断，能天使用“神就在那里”判断；差异来自前提，不来自换一组性格形容词。
- 重要人物可以说错，但错误必须稳定地来自其欲望、知识边界或自我叙事。
- 保持语言强度与人物位置相称。执行者的短句通常比理论独白更能表现制度内化。

## 选择与代价

- 关键选择应同时满足人物欲望并暴露其价值缺口。
- 让人物知道的程度影响责任，但不自动免责。
- 检查人物是否把代价转嫁给别人、主动承担、误以为自己承担，或把别人的代价登记为自己的功绩。
- 同一人物在不同卷可以重复同一种选择算法，规模逐渐扩大。

## 校验

- 如果删除人物的形容词，动作仍能证明她是谁吗？
- 善意、私欲和自欺是否共同存在，而非互相取消？
- 人物的终局选择能否追溯到早期欲望或误读？
- 对照人物是否共享一个深层问题，而不只是站在善恶两端？
- 人物是否以自己的词汇行动，而不是替作者解释设定？
- 人物的错误信念是否与世界事实分开记录？

## 失败方式

- 纯洁圣女、纯粹恶父、腐朽官僚、疯狂反派等单轴人物。
- 以“虚伪”概括所有复杂动机。
- 为制造反转，突然宣布人物从未爱过、从未相信或一直在演戏。
- 用长篇心理解释代替关键选择。
- 把人物受控制写成彻底免责，或把神的身份重叠写成责任消失。
- 用恋爱、英雄、救世主等类型称号提前替行动完成塑造。
- 让没有独立选择的群体只承担劳务和预定团灭，再把其死亡当作主要人物的深度。
