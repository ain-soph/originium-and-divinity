# 思想表达方法

## 目标

让思想成为人物必须作出的判断、制度允许执行的流程、物件发生的变化和代价的实际归属。不要先写观点，再安排人物轮流解释。

## 基本流程

1. 先在笔记中把思想压缩成一个可争论命题。
2. 找出命题中至少两个不能同时保全的前提，如事实与教义、个人判断与制度权限、普遍原则与私人占有。
3. 把不同人物放在同一个事实、程序或损失面前，使他们各自保留不同前提。
4. 让分歧改变选择、权限或代价；只有立场差异而没有后果，不足以构成剧情中的思想。
5. 用一句判词、一次动作或一个物件变化收束，不替读者完成全部总结。

## 可复用结构

### 同一事实，不同前提

- 不让人物只持有不同意见，而让他们决定“哪一个前提不可放弃”。
- 可颂临死时，莫斯提马保留“真神必传福音”，于是判莉夏为伪神；能天使保留“莉夏确实是神”，于是判定神不保证福音。
- 检查两种推理是否都从人物真实关切出发。莫斯提马的体贴必须真实，不能为了抬高能天使而把她写蠢。

### 相反行动，同一欲望

- 用相反选择暴露相同的自我叙事，比“正派／反派”并列更有力。
- 阿丽娜以“我替所有人死”取得救世主位置；凯尔希以“我必须为了所有人活”维持救世主位置。
- 不把这种对照简化成无私与自私。要追问两人都需要自己成为什么。

### 理念变成权限和流程

- 把抽象命题写成谁能批准、谁能行动、谁必须报告、谁承担试错。
- “制度反对的不是残酷，而是未经制度批准的残酷”应由申请、共刺激式批准、内部监察和错误结案共同显现，不由角色发表论文式演说。
- 执行者可以真诚信奉制度。思想恐怖来自合理职责共同产生残酷结果，不只来自坏人滥权。

### 理念变成物理操作

- 为抽象认知差异寻找一个不能被解释替代的具体操作。
- 向外走必须先把门向内拉开，使局部贪婪算法与全局路径发生物理冲突。
- 遗体变成糖，使“人口是可回收资源”不再只是国家宣传。

### 理念变成非对称命题

- 检查句子的方向，不默认“是”可以倒置。
- 身份包含、占有与采用不是数学等号；同时必须区分死亡前后的指称。对生前有限阿丽娜不能倒置身份，对1-6后已经由神／父承载的阿丽娜则不能假装她仍是受神施恩的人。
- 让人物因错误倒置而行动，可以同时表现世界规则和人物欲望。

### 跨制度复现同一语法

- 同一思想可在神圣契约、国家申请、教会教义、IRB批准和管理员权限中反复出现。
- 每次复现必须更换承担者、权限接口或代价，不能只换术语重复结论。

## 组织思想的四个问题

分析每个场景时回答：

1. 谁知道事实？
2. 谁拥有解释或批准事实的权限？
3. 谁作出选择？
4. 代价最终落到谁身上？

四者不重合时，思想冲突通常会自然形成。

## 表达强度

- 先让制度语言、职业语言或日常安慰承担思想，再考虑是否需要直接论辩。
- 允许角色只说自己职责范围内的话。军官介绍目标和报告责任即可，不解释免疫耐受或国家哲学。
- 允许一句话同时存在事实层、人物误读层和安慰层。“一定是的”既可以在事实层为假，在关系层又是真实的安慰。
- 让核心意象在后文改变含义。经文、糖、照片和传单应被重新执行，而非原样引用。

## 校验

- 删除作者总结后，读者是否仍能从选择和代价读出冲突？
- 每个人物是否真诚保护了某个前提，而不是替作者扮演错误答案？
- 思想是否改变了事件，而不只改变台词？
- 代价是否可见、具体，并落在确定的人身上？
- 重复出现的思想是否发生了尺度、权限或意义变化？

## 失败方式

- 让军官、医生、神或学者长篇解释主题和隐喻。
- 把人物分成代表正确思想和错误思想的两张嘴。
- 用“其实她只是自私”“其实他是好人”替代并存动机。
- 用一句道德判断封死仍应由情节承担的矛盾。
- 把身份包含误写成对称同一，把人物的妄想误记成世界真相。
- 只让象征对应名词，不让对应关系参与因果。
