# Memory笔记模板

## 章节笔记

```markdown
# 章节编号《章节名》

## 当前状态

- 正式正文／成形草稿／情节点提纲／空白。

## 作者思路

- 待定。

## 写作意图

- 待定。

## 想传达的思想

- 待定。

## 故事设计

- 待定。

## 核心画面

- 待定。

## 形式与语言

- 待定。

## 伏笔与回收

- 待定。

## 已确认

- 待定。

## 已否定

- 待定。

## 其他笔记与待确认

- 待定。
```

可以合并没有必要分开的栏目，但必须区分原文事实、作者确认与助手待确认归纳。

## 卷级总纲

记录当前完成状态、卷内因果、人物弧、写作意图、思想、核心画面、跨章伏笔和待处理事项。只收录真正跨越多个章节的内容。

## 整书总纲

记录项目定位、最高层设定、三卷结构、全书思想主轴、人物终局、反复意象、结局设计和跨卷待定问题。具体章节细节下沉到章节笔记。
