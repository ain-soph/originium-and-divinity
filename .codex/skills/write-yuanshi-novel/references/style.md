# 写作方法

## 核心审美

目标是荒谬、抽象、难以理解但内部精确的高维恐怖。不要默认追求现实主义对话、自然口语、顺滑因果或即时可解释性。

难以理解必须具有结构：异常表达应当连接后文的世界规则、身份关系、叙事层级或形式变化，使重读能够发现其精确性。

## 语言机制

- 允许结果先于过程成为边界条件，允许因果方向倒置。
- 让互斥状态同时成立，不急于判定何者为幻觉。
- 用“捕获、约束、映射、回收、结算、写入、加载、析构”等抽象或技术动词处理肉体、情感和叙事。
- 使用无施事者的被动句，使读者看见处理结果而看不见上层执行者。
- 允许人名退化为“讲述者、听客、旁观者、角色”等叙事功能。
- 保留有结构的代词歧义，使“她／祂／自己”的不稳定指向表现身份重叠。
- 身份判断中的“是”可以是非对称关系，不能默认当作数学等号倒置；但必须同时写明人物与时间点，不能让抽象规则覆盖作者确认的状态变化。生前有限阿丽娜是人；1-6死亡后重新站在阿丽娜位置上的主体已是神／父，因此“复活后的阿丽娜是神”是事实。这个特例不能外推成塔露拉等有限人物也自动是神。
- 时间限定可以后置并反向改写此前阅读。“莉夏就是阿丽娜，从故事开头”把关键尺度留到句尾才公布；神同时属于过去、现在和未来，不能为了线性时间说明把它改成更直白的第一人称时点句。后置带来的重读冲击本身就是功能。
- 使用顶真、平行、复沓和格式变化建立逻辑链，而非仅作音韵装饰。
- 常以较密集的句子建立异常，再用短句像判词、神谕或系统状态一样落槌。
- 把情感压缩进结构矛盾和客观事实，不直接解释人物有多恐惧、悲伤或痛苦。
- 保持克制。一个具体画面、一个抽象操作、一个矛盾结果通常已经足够。
- 同一意象若只承担一个精确判断，不以首尾重复自动制造结构。1-6只让食腐的鹰在复活后出现一次，集中完成“鹰仍把活着的神辨为死人”；章首再写一次会提前消耗这一矛盾。

## 修改判断

遇到不自然或难懂的句子时依次判断：

1. 它是否改变正常的因果、观察、身份或时间关系？
2. 它是否与后文规则形成伏笔或回收？
3. 它的歧义是否存在有限而有意义的解释空间？
4. 删除或自然化后，是否会损失高维视角？

前三项成立时优先保留。只有陌生感来自无收益的语病、重复信息或偶然含混时才建议修改。

## 生成限制

- 不把瞬间异常展开成连续、完整的动作过程。
- 不使用大量肌肉、呼吸、手指、视线等细节来“证明”体验真实。
- 不用“仿佛、似乎、好像”把真实异常降格成修辞比喻。
- 不主动解释人物为何没有注意、神如何控制、哪一种感知才是真的。
- 不为了文学感额外堆叠意象、形容词或拟人。
- 不消除承担身份重叠功能的代词歧义。
- 不把“神是某人”自然化成“某人就是神”，也不因神能以某人身份行动就取消该人物自身的有限性与责任。
- 不把刻意异化的对话改成正常人更可能说出的句子。
- 不用泛化的类型文学套语替代精确的逻辑异常。
- 不用“情书、信物、少女心事”等现成言情标签，替人物提前解释复杂的爱情、占有、罪责与身份关系。可以写爱情，但应让物件的实际流转、人物承担的代价和后文回收定义关系。
- 阿丽娜与塔露拉就是恋人关系。这不是需要回避、否认或用其他关系替代的解释；克制之处只在于正文不必刻意指明“她们是恋人”，也不必采用言情类型的固定话语。
- 阿丽娜保存塔露拉的文字、冒认她的身份与罪责，首先可以是恋人之爱在具体处境中的行动。文字、身份、罪责、占有和替死丰富这段爱情，但不是用来证明“她们其实不是恋人”的替代关系。

## 负面样本

- 1-5“她把它折成四折，当情书收着”已被作者判定过于言情，后续应删除“当情书”。
- 失败机制：直接命名“情书”会提前替物件规定阅读方式，使同时属于革命宣传品、私人文字、罪证和替死物证的传单只剩下一种现成的言情功能。问题不在浪漫或恋爱本身，而在类型标签过早说尽了关系。
- 修正方向不是寻找更文学的浪漫同义词，而是保留“抽走、折叠、贴身保存”等客观事实，让冒认作者和替人赴死在后文完成意义。
- 1-4.5结尾的一版候选稿把“非当日目标、错误杀伤申请、未获批准、预防性清除、多少处理都要报告”逐项改成塔露拉与军官的连续问答，已被作者判定为流水账。
- 失败机制：memory中的逻辑骨架不能逐条分配给人物口头说明。即使句子短促、符合职业口吻，若没有新的物件、程序动作或状态变化，对话仍然只是设定清单。
- 修正方向：让申请书、批文、报告、物证或其他已建立装置在场景中真正改变权限和人的状态；对话只刺破其中一个矛盾。最后再用一句变换物件功能或观察方向的判词收束。
- 1-4.5曾有把任务边界逐项交给塔露拉盘问的长对话，该方案仍属失败：它让平民替作者索取整套制度说明。作者最新却确认保留压缩后的“弑父也不查？塔露拉没敢走”：证件虽已递还，军官尚未明确放行，“没敢走”使这句话成为对自己是否获准离开的恐惧确认，而非逞强邀请复查。
- 判断人物是否“有资格发问”不能只看问句字面，还要检查批准状态、相邻动作和叙事功能。1-4.5中军官随后明确说“我今天查的不是你”并转向村口，塔露拉才低头走开，又被村口喧嚣逼停；这既保持权力不对称，也把塔露拉连续转换成内部处决的观察视角。若担心问句先被读成挑衅，可把“没敢走”的恐惧提示前置，而不是删除整个视角桥。
- 1-6“这无疑问是神的奇迹”是作者确认的刻意异化，不得自然化成“这无疑是”。它把“无疑是”与“无疑问”叠合：前半章不断追问谁有问题、该信什么，复活后叙述却把奇迹判成不再受理疑问的状态；紧接着塔露拉仍可追问称谓，因而被取消的是对奇迹成立与否的质询，不是全部语言能力。
- 不把高维改写补成普通连续动作。1-6局部现实重置后照片仍在塔露拉手里，是因为向霜星交付照片的事件被取消；补写“夺回”会把现实重写降格成物件交接。“霜星从未来过”也不窄化成空间说明，它故意让被删除事件的作用域保持不安定。

## 回答作者

- 先判断作者意图和句子的结构功能，再评价自然度。
- 提供修改稿时尽量短，避免用多个低质量备选淹没作者的判断。
- 明确指出建议是在修复无效阻塞，还是改变审美方向。
- 作者否定方案后，提取失败机制并更新负面样本，不只更换同义词。
