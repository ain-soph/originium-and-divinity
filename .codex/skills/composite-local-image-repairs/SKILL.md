# 局部修复图的布尔遮罩合成

目标：只采用修复图中需要修好的区域，其余像素完整保留原图。用户要求的是基于现有图片的确定性合成时，不再调用生成模型重绘整张图。

## 为什么要混合原图与修复图

局部修复的目标虽然只是某个区域，但扩散模型的加噪、去噪过程可能同时作用于非修复区域，未必能完整保留这些区域的原始像素。结果是需要修复的部位变正确了，原本不需要修复的高质量区域却出现噪点、细节退化，变得不清晰。本技巧正是为了解决这种局部修复带来的画质损失。

因此，最终图应混合两张图片：**修复区域采用新的修复图，非修复区域采用旧的原图**。布尔 mask 明确决定每个像素来自哪张图，使修复结果与原图清晰细节同时保留下来。不要因为新图的局部结构更正确，就用它替换整张高质量原图。

## 输入与判断

- 明确第一张为原图 A、第二张为修复图 B。读取实际尺寸和颜色模式；两图必须具有相同尺寸及空间对齐关系。尺寸相同不代表内容对齐，须目视检查脸、衣服、背景等稳定位置。
- 若错位，不要静默缩放或移动原图；先解决修复图的对齐问题，再圈选。附带脚本会拒绝尺寸或模式不一致的输入。
- 用多模态视觉查看两张完整图，再查看修复部位的原尺寸或放大裁剪。必要时给检查用裁剪加坐标网格；坐标统一回到完整图的左上角原点，x 向右、y 向下。
- 根据用户要求和真实画面手动选定区域。不要将两图的全局像素差分阈值直接当作修复 mask：生成模型对非修复区域的噪点恰恰也会造成差分。

## 选区边界

- 用一个或多个多边形圈住完整修复对象及必要的邻接区域；无需使用覆盖大片背景的矩形。
- 必须包含**原图与修复图轮廓的并集**。例如补手指时，不仅选中新手指，也要覆盖旧手指位置、移动后的轮廓和指缝，否则会残留旧手指、重影或截断指尖。
- 手部案例应覆盖手指、手掌、手套、手腕绑带及少量相邻袖口；根据实际改动决定范围，不把整条手臂自动纳入。
- 在轮廓外围留少量余量，覆盖原有抗锯齿、虚焦边缘和变化的遮挡关系；边界尽量落在稳定的背景或自然衣物接缝上。避免切穿指尖、关节、绑带或高对比边缘。
- 余量按图像分辨率与实际模糊范围判断，不固定像素值或覆盖比例。多个选区之间不需要连接。

## 严格二值合成

mask 为形状 `(height, width)` 的布尔数组，False/0 选择 A，True/1 选择 B：

```python
final = np.where(mask[..., None], repaired, original)
```

- 严格布尔模式下不羽化、不混色、不做泊松融合，不对成品统一去噪、锐化、调色或缩放。每个输出像素必须完整来自一个输入。
- 若边界有接缝，先调整选区位置和范围；若需改用软遮罩，须明确它已不同于用户要求的 0/1 合成，不擅自替换交付。
- 默认另存文件，不覆盖任何输入。

## 可复用脚本

使用 [scripts/composite.py](scripts/composite.py)，依赖 Pillow、NumPy。把目视判断的完整图坐标保存为 JSON：

```json
{"polygons": [[[100, 200], [140, 180], [160, 260], [110, 270]]]}
```

该坐标仅说明格式，不能复制为其他图的实际选区。执行：

```bash
python scripts/composite.py --original '/path/original.png' --repaired '/path/repaired.png' --regions '/path/regions.json' --output-prefix '/path/result'
```

也可用 `--mask '/path/mask.npy'` 替代 `--regions`，复用已有布尔数组；脚本拒绝非 0/1 数值。路径相对当前工作目录解析。

脚本保存：

- `result.mask.npy`：真正的二维 bool 数组，是机器使用的规范 mask。
- `result.mask.png`：索引值严格为 0/1 的 PNG，以黑/白调色板显示。读取索引数组时保留 P 模式；转换为灰度或 RGB 后白色显示值会变成 255，不能混淆显示色与索引值。
- `result.final.png`：无损最终合成图。
- `result.overlay.png`：原图上以青色标明选区，仅供检查，不参与合成。

## 检查与交付

重新读取已保存的 mask 和成品，验证尺寸一致、mask 只有 0/1，以及：

```python
np.array_equal(final[~mask], original[~mask])
np.array_equal(final[mask], repaired[mask])
```

脚本完成数值验证后，还须目视查看选区叠加图和最终图，必要时放大边界，确认没有漏选、残影、截断或明显接缝。数值正确不能代替选区判断。

交付最终图、布尔 mask 和选区预览的本地链接，说明尺寸与原图区域逐像素一致的验证结果。覆盖比例可以辅助说明，但不是质量目标。
