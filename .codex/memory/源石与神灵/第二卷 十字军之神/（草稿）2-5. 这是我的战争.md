# 2-5《这是我的战争》

## 当前状态

- 原文件目前与2-4《作战动员》完全相同，尚未形成独立章节。

## 预定功能

- 应承接动员进入真实战争，写出信仰、源石经济、物流和普通人的生存代价。
- 标题暗示重点不应只是宏大战役，而应包括平民和参与者的私人战争经验。

## 可用设计

- 十字军在信奉该宗教的外国城市获得战斗加成，是世界被游戏规则显式侵染的表现。
- 企鹅物流可能承担源石与军需流通，使第一卷大开采和本卷战争连接。
- 德克萨斯、可颂、莫斯提马可以分别提供局外、平民和旧友视角。

## 核心画面

- 尚待作者从战争草稿中确定。

## 待处理
