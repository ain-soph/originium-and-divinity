# 2-4《作战动员》

## 当前状态

- 完整动员提纲；与2-5当前正文相同。

## 作者思路

- 拉特兰所有普通人收到神启，唯独教会人员没有。
- 主教误以为信众造反，并因被神遗弃而恐慌、自杀或镇压。
- 圣座审议教会“要杀死基督”的行为并解散教会。
- 能天使自认不会讲话，莉夏让她只管上台念主祷文；经文随后自动组织成末日十字军演说。
- 信众响应，德克萨斯和莫斯提马成为少数不能融入集体启示的人。

## 写作意图与思想

- 直接神启摧毁以解释神意为权力基础的教会机构。
- 主祷文中“国度、权柄、荣耀”被转化为战争动员。
- 群体虔诚与群体暴力共享同一节奏和语言。

## 核心画面

- 教会人员在没有启示的城市里惊慌失措。
- 能天使像小丑一样站上万众瞩目的讲台。
- 经文从祷告连续变形为最后十字军宣言。
- 无数白衣信众举棕树枝高呼救恩。
- 德克萨斯在人群中感到惶恐。

## 待处理

- 压缩经文清单，使演说形成明确推进而非素材堆积。
- 设计莫斯提马与德克萨斯在动员后的具体反应。
