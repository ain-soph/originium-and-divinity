# 2-3《至高天的陨落》

## 当前状态

- 情节与对话提纲。

## 作者思路

- 神来到拉特兰“取祂的义”。
- 教会派莫斯提马说服能天使；两人久别重逢并重走年少时每周弥撒的路径。
- 能天使直接识破莫斯提马受命而来；莫斯提马承认制度任务，也承认私人思念。
- 神准备书写布告。教会询问是否寻找遗失圣物笔，莉夏指出被神使用的物才成为圣物。

## 写作意图与思想

- 让私人重逢承担教会与直接神启之间的冲突。
- 圣物没有先验神圣性；神的使用反向赋予物件神圣身份。
- 这一逻辑与登神仪式相呼应：不是仪式制造神，而是神完成的仪式才成立。

## 核心画面

- 能天使走在前面，不回头说“他们派你来的”。
- 久别两人在教堂共同参与弥撒。
- 普通笔因神准备书写而成为圣物。

## 待处理

- 补足教会提出的条件、莫斯提马说服内容及能天使的选择。
