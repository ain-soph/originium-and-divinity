# 1-9《End Like This!》

## 当前状态

- 情节点与身体描写草稿；作者当前倾向从第一卷后半删除这一场景。

## 作者思路

- 莉夏让塔露拉在爱国者食物中加入“止疼药”，实际是吗啡。
- 爱国者发狂并恢复食人冲动，却因源石病失去牙齿，无法顺利进食。
- 莉夏要求把霜星头颅交给爱国者；塔露拉明知失败仍先反抗。
- 塔露拉直视爱国者衰败身体，并得知感染者最终都会如此。
- 此后塔露拉变得封闭、冷漠，不再询问莉夏命令的原因。

## 写作意图与思想

- 把英雄、父亲和温迪戈降格为无法进食的衰老肉体。
- 让塔露拉亲自处理霜星与爱国者之间的亲情，耗尽她最后的抵抗。
- 源石病结局反照塔露拉在1-3主动感染时未曾真正理解的代价。

## 核心画面

- 没有牙齿的老狮子面对猎物。
- 爱国者头部被源石毛刺和结晶占满。
- 封存的霜星头颅被作为食物投向父亲。

## 待处理

- 作者当前判断该段没有形成新的思想表达或有深度的画面，主要效果只是猎奇；若不能使爱国者真正改变矿场、战争或塔露拉的政治选择，不再为保留身体奇观而补因果。
- 若整段删除，1-8中仅为本章服务的“凿下并保存霜星头颅”也应重新审查；没有后续必要功能时一并删除。
- 爱国者这一人物是否在哥伦比亚战争或革命政治中另有不可替代功能，尚未决定；删除旧终局不自动等于删除人物。
