# 1-7《整合运动》

## 当前状态

- 不带版本前缀的现行成稿；作者于2026-09-01确认1-1至1-7已经写完。
- 正式章名是《整合运动》。旧《小开采》修改稿3及更早两版1-7都只是历史工作稿，不再承担当前章界、台词或物件状态的入口。

## 作者思路与写作意图

- 用《路加福音》14:28“先算计花费”做题辞，把1-6不先公布价格的神圣约定，与本章要求把代价和停止方法写在签名之前的人间约定对照。
- “霜星活到了第二天”直接回应1-6末句：神谕已经宣告价格，却不替塔露拉自动执行。霜星不知道自己已被写入另一个约定。
- 革命只回答了矿场应当归谁，没有自动回答归还劳动者以后是否还应继续开采。本章用“矿场归我们了。然后呢？”把所有权正义与使用正义分开。
- 革命矿场的解放是真的：危险岗位自愿报名，撤回不扣口粮，黑签从强迫下井反转为阻止人超过防护限额下井；劳动热情、效率、笑容和尊严都不是等待后文揭穿的宣传。
- 塔露拉仍然参与公共行动，但不等于撤回1-6的动机换轨。她说“这就是整合运动的意义”，又在心中对阿丽娜说“这就是我们公义的道路”：同一矿场既是真实的劳动解放，也是她拿给神看的人间反证。

## 故事设计与物件链

- 塔露拉第二次到矿场。第一次已用霜星交付的实体黑签取得矿工识别，发完传单离开；现在矿工在雪怪小队封住外围巡逻线的配合下赶走矿务官和卫兵，占领粮仓、炸药库和矿站，但主动停住绞车。
- 现实倒计时为八天粮食，第九天断粮；退热药已用尽，矿灯大半损坏，仅四套防护服能够密封。不开井会饿死，开井会继续制造矿石病，两个代价都没有被消除。
- 现行《整合矿场临时开采约定》只开一口旧井，以红线圈定矿图边界，把产量牌的“不得少于”改成“不得多于”，上限为旧最低定额的四分之一；危险岗自愿报名，撤回不扣口粮，每次下井和装车须由矿工代表与安全负责人共同签字，革命胜利当日自动终止。
- 约定没有帝国印章，抄成三份。矿工代表先签，霜星在安全栏签字，塔露拉在采运批准栏签字；三人各持一份。
- 霜星由塔露拉提名为首任安全负责人，又获得矿工“让抽过黑签的管”的认可。矿井运行钥匙和黑签箱钥匙归矿工代表，霜星另持安全锁钥匙；她的后续守界权有共同治理、劳动者授权和物理权限的正文起点。
- 首日九人报名，一名调车员因女儿发烧撤回且仍领口粮；余下八人争四套防护服。霜星把自己当年的黑签与其他七签混入箱中，抽到黑签者当日不得下井，转而检修货车和封箱台。
- 中午前产量碰到红圈，先停采掘设备，保持绞车把所有人送回地面；人员出井后矿工代表拉总闸，霜星再上安全锁。“那是车厢的空缺，不是你们的空缺”把运输容器的未满与劳动者的人格／义务分开；塔露拉在约定生效第一天明确下令“停”。
- 首批未经精炼源石已装入封存旧棚车，只达约定数量，车厢仍空大半。交换清单是面粉、退热药、矿灯、炉芯；这些物资尚未取得。

## 章末的声音与交互边界

- 纸面物件状态仍是：车门已合，当日双签只能装车，不能放行；放行单的目的地栏与护送栏依然空白。
- 但现实行动已在口头上确定：霜星指派塔露拉带雪怪小队护送第一单交易，并明说哥伦比亚很乱、行动需保密；霜星自己因矿工需要她而留守矿场。
- 霜星说到“所以到了那边以后……”并停顿后，叙述转为“过一会儿，莉夏面容的白发兔耳少女继续说”，神／父只向塔露拉说【记着，不许说俄语。】
- 这不是霜星与阿丽娜对话，也不表示霜星看见、听见或验证神谕。它是塔露拉独有感知中的话语接续：复活后阿丽娜仍只与塔露拉发生角色层交互。
- 正文末的`<!-- “好。” -->`是不渲染的HTML注释；现行可见文本不让塔露拉口头回答。

## 人物与长线功能

### 塔露拉

- 她在已知神向自己要求霜星死亡后，没有立即杀人，也没有警告霜星；反而将霜星写成临时约定中不可绕过的安全权限。她“没有告诉霜星，另一个约定也写了这个名字”，已建立私人利益冲突与隐瞒。
- 她在人们期待破例时命令停产，说明本章的有限开采不是她一开始就要扩张的欺骗。后来的责任必须来自她如何改变，而不是反向伪造本章。

### 霜星

- 她明知开井会继续制造矿石病，却因断粮、无药和防护不足提出小量开采，因而是有限求生方案的真正创制者，不是事后才突然出现的反矿业人物。
- 她把自己的黑签改造为保护他人的装置，在劳动热情最高时上锁停井，又因实际安全权限和矿工信任成为后半卷长期守住上限、边界和到期条款的人。
- 她把雪怪小队全员交给塔露拉，自己留守矿场；这为1-8中雪怪全灭后她不再凭武装，而凭制度、革命元老身份和劳动者信任继续守界做好了转换。

## 1-8的准确入口

- 已完成：首批源石开采、封箱、装车与关门；产量有限，车厢大半空置。
- 已口头确定：哥伦比亚方向、塔露拉带雪怪小队全员护送、霜星留守矿场，以及神只对塔露拉发出的“不许说俄语”。
- 仍未完成：纸面目的地栏和护送栏未填，列车未发，交易未成，回程物资未取，路线尚未证明可行，雪怪小队仍全部活着。
- 1-8不再负责揭示或首次说出“不许说俄语”，而负责执行这条已经发出的命令：完成第一次哥伦比亚走私，现场化表层冲突与塔露拉的主动选择，使交易成功、粮药等物资返回、线路可行性成立，同时让雪怪小队全灭，霜星本人继续存活。
- 粮仓只够八天；首次走私与粮食返程原则上须在第九天断粮前完成，若超时则正文必须直面写出断粮。
