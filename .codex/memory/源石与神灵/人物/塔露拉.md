# 塔露拉

## 身份与别名

- 塔露拉·雅特利亚斯；德拉克皇女、科西切养女、革命者与故事讲述者。
- 神可以是塔露拉，塔露拉属于祂；这种非对称身份包含不能反推成塔露拉穷尽神，也不能取消她作为塔露拉的连续责任。

## 当前定位

- 全书主要视角与道德断裂中心。她从反抗神、国家和长生种的人，逐步走向与神共谋，并最终索取自己曾反对的永生。
- 第一卷后半当前还承担国家权力弧：她在正式上台前经历乌萨斯入侵哥伦比亚，战后刺杀卡谢娜，再由感染者民众推举为国家领导者。她不必继承黑蛇名号，却客观进入与黑蛇同构的最高协调位置。

## 核心矛盾、欲望与恐惧

- 救世欲、占有欲和求生欲彼此纠缠。
- 宣称普遍平等，却在阿丽娜之死面前退回“阿丽娜是我的”。
- 强烈要求自己掌握命运，实际只能以局部知识和道德启发式理解路径。
- 最深恐惧包括失去爱人、失去主体性、死亡以及自己已经成为曾经憎恨之物。

## 认知与价值

- 人的局部优化算法代表：只接受眼前一步立刻靠近目标，无法理解全局最优可能要求先退后。
- 对制度暴力和阶级不平等高度敏感，但私人悲痛会击穿她的普遍原则。
- 卡谢娜上台后，她真切感到整个乌萨斯比科西切时更糟：科西切的圆滑尚会给感染者与平民留少量可以求情、拖延与破例的空间，卡谢娜则为集体最优把这些空间当作漏洞删除。这不使她怀念或原谅科西切。
- 草稿中需要接受莉夏关于作恶的训练：必须先理解受害者的生命重量，再决定是否仍要行恶。

## 人物弧

- 主动感染、与莉夏立约并弑父。
- 阿丽娜替她认罪死亡后，她屠杀村庄、吞下由遗体回收的糖，完成第一次重大道德越界。
- 为让阿丽娜重新站在自己面前而完成握手，随后得知代价是霜星死亡；她把结果理解为恋人复活，但现行客观设定是站起来的主体已是神／父。旧爱国者食人终局当前倾向删除，不能再把她的转变写成连续身体猎奇的被动累积。
- 革命资源匮乏时，因霜星的矿场经验批准占领区小量开采与贸易。她最初真诚地把它视为邪恶但必要的临时例外，并打算胜利后废弃。
- 1-7中她在《整合矿场临时开采约定》的采运批准栏签字，接受一井红线、旧最低定额四分之一的日上限、自愿报名、撤回不扣粮、矿工与安全双联签及胜利日终止；首日达到上限时她明确拒绝破例。
- 霜星只向她提供矿区走私／旧铁路信息；由她主动联系哥伦比亚，以有限源石交付换取粮药、武器、资本与工程援助。她因此在正式上台前已经以未来国家资源作出近似主权承诺，并亲自承担把求生线路升级为代理人契约的责任。
- 第一次实际交易的准备已在1-7章末落地：霜星基于行动需要把雪怪小队全员交给她、自己留守矿场；神／父以阿丽娜身份在塔露拉的私人感知中接续霜星停顿的话，只对她说“不许说俄语”，霜星与雪怪均不感知或验证这条命令。1-8将让塔露拉在中止交易、回头接应雪怪与按约带走物资、保住买方及线路之间选择后者；交易成功、物资返程、路线成立，雪怪全灭。这是她第一次为了铁路带来的真实善果放弃具体的人，也预演后来为了国家物质生活杀死霜星。
- 她批准革命者共选乌萨斯旧矿线，并以临时运输令、报酬、资源征用和未来源石交付承诺动员本国铁路人员与工业储备修复、延伸支线；哥伦比亚负责国境另一侧、固定收购、信用和接驳。两侧合龙后，外国机车、接口人员、合同与局部调度权随灌流越境，旧政府据此发动战争。塔露拉未必知道这套免疫解释，但她必须看见乌萨斯最后通牒所要求撤回的正是自己签下的援助关系，以及被这份关系调动的本国铁路。
- 她与霜星看见感染者矿工不再抽黑签、主动报名危险岗位并因自主劳动获得真实幸福，真诚认为革命道路已经在矿井中得到证明。她没有看错劳动解放；她后来犯下的尺度错误，是把矿井内部正义直接外推为源石铁路与全球循环的正义。
- 通过矿场、铁路和哥伦比亚战争从私人交易重新进入公共政治；杀死卡谢娜后，被感染者民众推举领导国家，成为她所反对结构的功能继承者。
- 她在1-6说“整合运动和感染者的理想，就再和我没有关系了”，退出的是把集体理想当作终极目的的领袖身份，不是整合运动的物理现场或后续公共行动。此后她仍可进入矿场、贸易、战争与国家权力，但同一行动的内在方向逐渐转为人与神之间的对抗、履约、占有和控制；不需要另写一次离队后“重返革命”的仪式。
- 她在感染者矿区看见了不依赖黑蛇信号的真实自治成功，因而杀死卡谢娜时相信全国人民也会自行组织起来。她错在把感染者平行网络的成功外推给已被旧制度塑造成信号依赖性正常组织的大部分非感染者；结果是她拒绝继承的窗口内，大部分非感染者随旧政府职能失效而死。
- 革命成功后，群众因贸易带来的粮食、药品和取暖而拒绝回到旧生活，要求把临时开采扩大为国家经济建设；她必须决定是否让自己原先的道德承诺凌驾于这些人的当下生活。
- 霜星活到新共同体建立，并在雪怪全灭后长期凭统治集团席位、矿业安全联签与矿工／铁路劳动者信任阻碍扩采。最后一次集团会议破裂后，矿务、铁路、财政、医疗、军务等真实利益共同要求清除霜星并拆除制度刹车；塔露拉不是被动接受结果，而是把集团决议转成全国有效命令并亲手杀死霜星。
- 她从1-6起始终知道神要求霜星死亡，却向统治集团隐瞒这一私人利益冲突。现实政治已经为她提供充分理由时，她仍拥有否决、拖延、公开审理、辞职或警告霜星的路径，却选择让集体意志与自己的神圣债务落在同一刀上。这是她客观成为新root／黑蛇同构位置的第一次建国罪行。
- 第三卷批判凯尔希和长生种，最终因临死恐惧向莉夏索取永生。

## 关系

- 阿丽娜：恋人。爱情无需刻意命名，应由保存文字、替罪、占有死亡意义和后续回收自然显现。1-6以后塔露拉是复活阿丽娜唯一的交互对象，也是唯一能感知、听见并回应她的人；无人能替她验证神谕或分担解释责任。
- 莉夏：女仆、朋友、契约对象、神灵与高维压迫者；亲密和恐怖不能拆成两套互不相关的关系。
- 科西切：养父。她以为自己只在杀死暴君，实际面对一个理解命运并接受死亡的父亲。
- 霜星：革命同伴与后来被她用于兑现神圣交易的代价。
- 爱国者：旧草稿中的下一名身体受害者；该终局当前倾向删除，人物关系若保留需另找政治或战争功能。
- 卡谢娜：科西切之后的黑蛇、哥伦比亚侵略战争时期的国家首脑与她第二次刺杀的对象。二人冲突的核心不是私人恩怨，而是杀死首脑能否消灭最高协调职位。
- 卡谢娜死后的非感染者大规模死亡，使她的第二次弑杀不只是解放动作：她拔掉了压迫人民的根权限，也拔掉了正常乌萨斯社会唯一会发出“现在可以行动”的信号器官。

## 语言与行为塑造

- 允许出现“这结果不意外，但过程却离奇”等因果和信息顺序异常的说话方式。
- 情感应压缩进选择、物件和逻辑矛盾，不默认扩写为现实主义心理独白。
- 她会根据现实权力位置收束行为。1-4.5中证件虽被递还，军官尚未明确放行；“弑父也不查？塔露拉没敢走”现行解释为她不敢擅离、确认自己是否真正获准离开，而非主动邀请复查。军官明确说“我今天查的不是你”后她才低头走开，又被村口喧嚣逼停，继续作为内部处决的观察视角。

- 抱着科西切尸体放声大笑。

## 关键选择与代价

- 请求科西切今日死，随后无法撤销结局。
- 将阿丽娜之死登记为私人所有，杀死全村。
- 在哥伦比亚战争与卡谢娜之死后接受感染者民众的授权，成为国家最终协调者；她的权力来源与黑蛇不同，结构功能却相近。
- 她接受授权时已无法挽回大部分死去的非感染者；现行高潮让她以首次最高权限行为撤回四项杀伤命令、恢复剩余非感染者的生存信号并调度铁路，随后才签署永久矿业法和源石出境许可。

- 杀死霜星时，集体表决、国家批准和神谕授权可以同时存在，却都不能替她免责；她必须参加决定、拥有拒绝权、主动使决议生效，并在霜星死后亲自签署删除限期与上限的永久矿业制度。

## 待确认

- 各卷中祂具体在何时以塔露拉的身份行动或说话，仍需逐场标注；“神是塔露拉”不等于塔露拉取得完整神性，这一方向已经确认。
