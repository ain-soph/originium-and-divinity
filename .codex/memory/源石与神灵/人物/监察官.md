# 监察官

## 身份与别名

- 官职确定为“监察官”。
- 对应免疫耐受与共刺激审批机制中的制度性审查角色。

## 当前叙事功能

- 审查体系内部军官的反应阈值和执法资格。
- 对缺乏批准的杀伤倾向进行清除，即使当事军官尚未真正实施执法。
- 作为悬在军官头上的审查压力，也影响1-5传单案的结案。

## 核心思想

- 制度并不首先追问冲动是否残酷，而是追问残酷是否经过它的批准。
- 对官员的高压可以被制度及其执行者解释为对平民的仁慈。

## 禁止误读与负面样本

- 不改称检察官；当前正式称谓是“监察官”。
- 不必将其塑造成私人报复者；其恐怖首先来自正常运转的制度职能。

## 待确认

- 现行1-4.5与1-5均不让监察官本人出场；他只通过【不予批准】批复、签字、复核栏与军官对内部审查的压力存在。未来章节是否让他现身另行决定。
