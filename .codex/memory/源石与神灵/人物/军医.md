# 军医

> 2026-09-04正文核对：依据第一卷现行无版本前缀正文1-6更新。下文标为“现有文本”的内容是原文整理，不是作者新增确认；既有作者决定继续保留。涉及1-9及以后的规划与跨卷结论沿用旧记录，本轮未更新、未重审。

## 身份与别名

- 1-6成年仪式医疗帐篷中的军医，负责宣读知情条款并执行额前冰锥净化。

## 当前叙事功能

- 执行与“成年”绑定的脑部手术，使对人格和思想的切除被包装成标准医疗程序与社会成熟仪式。
- 现有1-6宣读“额前思想区”净化条款：预期消除思想不洁，风险是主动性、计划性和远期忧虑同时消除；撤回同意等于放弃替代处决。表格与程序性终止申请书出自同一油印机，阿丽娜签下最后一行字后接受操作。军医没有展开私人解释，仪式很快完成、帐篷没有喊叫。

## 语言与行为

- 适合使用知情同意、风险告知、流程确认一类程序性语言。
- 不需要明显恶意；平静、熟练和合规本身即构成恐怖。

## 禁止误读与负面样本

- 不把军医写成享受折磨的变态医生。
- 不用医学说明替读者完整解码隐喻。

## 待确认

- 姓名、军医与军官、监察官的具体组织隶属关系；不能仅因同场执行就补成独立决定赦免与处决的人。
