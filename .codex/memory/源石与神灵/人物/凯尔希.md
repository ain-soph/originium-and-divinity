# 凯尔希

## 身份与别名

- 凯尔希；长生种、院士、罗德岛核心人物；被莉夏称为“泰拉的女祭司，凯尔希·伊丽莎白伯爵夫人”。

## 当前定位

- 第三卷科研伦理、阶级长生、世界溢出和“谁有资格成为英雄”的主要对立人物。

## 核心矛盾、欲望与恐惧

- 以知识、拯救世界和制度权威证明自己应当长生，却拒绝成为结束危机所需的牺牲。
- 对1024岁边界和死亡高度恐惧，为此修塔、换血换器官并建立生命链接。由于现行1-3已将感染者通用寿命上限改为`uint14 / 16383`，这1024边界之后只能是凯尔希自身字段或另一系统边界的待确认设计，不是感染者的通用寿命类型。
- 她不仅认为自己曾经拯救世界，也需要“救世主”成为自己不可被替代、不可被牺牲的身份证明。

## 认知与价值

- 相信形式完备的科研、IRB和同行审议能够建立合法性。
- 拥有管理员权限或接近权限，却未必真正理解、掌握底层调试命令。

## 人物弧

- 通过学术会议暴露长生工程与感染者胚胎实验。
- 以遗忘之塔、骨髓和WeedGuy维持生命。
- 年龄溢出使世界发布杀死她的任务；莉夏反而保护她，使任务无法结算。

## 关系

- 塔露拉：伦理质询者，也是最终重复其求生逻辑的人。
- 莉夏：高维对手、保护者与真正掌握塔用途的人。
- 能天使：以她为“伪英雄”对照，质问谁承担代价。
- Monster：其战斗单位或身体外置力量。
- 阿丽娜：跨卷结构对照。两人都从救世主位置确认自己的非凡；阿丽娜以自我牺牲取得这一位置，凯尔希则以救世功绩论证自己必须继续活着。

## 核心画面

- 全球医学会议上接受775个胚胎与IRB批准号的质询。
- 1024岁生日导致World.exe停止响应。

## 禁止误读与负面样本

- 不写成只靠阴谋维持权力的简单反派；其知识、救人贡献和制度合法性必须真实存在。
- 不因其贡献而免除让他人承担长生代价的责任。
- 不把她与阿丽娜简化成“自私者／无私者”的二分；两人的行动方向相反，却共享救世主式的自我例外化。

## 待确认

- 她、Monster、WeedGuy和遗忘之塔的精确生命链接机制。
