# 村长

> 2026-09-04正文核对：依据第一卷现行无版本前缀正文1-6更新。下文标为“现有文本”的内容是原文整理，不是作者新增确认；既有作者决定继续保留。涉及1-9及以后的规划与跨卷结论沿用旧记录，本轮未更新、未重审。

## 身份与别名

- 现有1-6明确出场的村庄负责人；1-5没有以“村长”称谓独立出场。

## 当前叙事功能

- 现有1-6受村民推到塔露拉面前说明阿丽娜之死，先说她替传单认罪；面对“军队把她杀了”的问法正要点头，被塔露拉推开并改问孩子。随后以“这是传统”“村里所有人死了都是这样”解释遗体回收。事实说明与自保姿态同场存在，不把被打断的点头写成已讲完的谎言。
- 塔露拉屠村的第一刀明确刺穿他的胸口，又用他的衣服擦刀，使解释制度的人先承受私人复仇。

## 语言与行为

- 不必主动威胁；越像在耐心解释人人都懂的正常规则，制度寓言越成立。

## 禁止误读与负面样本

- 不把所有制度罪责都人格化到村长身上。
- 不将塔露拉杀死村长自动写成完成正义。

## 待确认

- 他对制度的内在信服程度、姓名及任职经历仍未展开。旧“这是乌萨斯合国的传统”不是现行台词；当前只说“这是传统”。
