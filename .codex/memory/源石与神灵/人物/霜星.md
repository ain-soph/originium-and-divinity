# 霜星

## 身份与别名

- 霜星；雪怪领袖；爱国者的女儿位置；阿丽娜的宗教启蒙者。
- 有矿场抽黑签的出身；这段经历使她能够为革命接管矿场、设计小量开采和贸易提供实际知识，而不只承担受害者背景。

## 当前定位

- 第一卷“福音是否真是好消息”的信仰试验者、革命早期有限矿业方案的提出者，也是塔露拉后来为复活阿丽娜而支付的代价。她把前半卷的神学索取与后半卷的资源索取连接起来。

## 核心矛盾、欲望与恐惧

- 相信神带来福音，因此难以回答神为何允许麻雀、奶奶与普通人坠落。
- 她的信仰仍依赖神的良善承诺，与后期能天使“不因福音而信”形成差异。
- 她亲身知道人间矿井会向劳动者收费，因此不会把矿业本身理解成没有代价；她建议的是为革命筹资的有限、临时开采，而非国家后来“自然无限供给”的无边界扩张。

## 人物弧

- 教阿丽娜经文和主祷文。
- 以黑签矿场经验建议塔露拉在占领区接管矿场、小量开采并贸易，作为革命资源不足时的临时方案；具体政策边界和场景尚待设计。
- 亲眼看见革命矿场取消黑签、工人主动报名危险岗位且真实享有劳动尊严与收益，与塔露拉共同感到欣慰。她留下的有限方案不仅带来物质收益，也确实改善劳动关系；后来的全球危险不能把她此刻看见的解放改判为虚假。
- 第一次对哥伦比亚走私时，她把雪怪小队全员交给塔露拉护送首批源石。塔露拉完成交易、带回物资并证明线路可行，雪怪却全灭。霜星因此同时面对真实救命善果与所有伙伴的死亡。
- 她不再在矿场起步后立刻死亡，而是活过铁路扩张、哥伦比亚战争、卡谢娜遇刺与新共同体建立。雪怪全灭以后，她持续依靠临时矿法创制者、矿业安全联签人、革命元老、政府成员以及矿工／铁路劳动者的信任守住产量上限、矿图边界与“胜利即停止”的期限，不再拥有雪怪武装。
- 革命胜利后，她反对把临时求生方案扩大为国家长期经济原则：自己曾是矿工，不愿让整个社会从强迫下井转为只能依靠不断下井才能维持生活。群众获得的粮药、取暖、工资与尊严都是真的；她的反对也真实要求社会承担降产、紧缩与重新变穷的代价。
- 源石贸易形成的矿务、铁路、财政、医疗、军务与受益群众逐渐构成支持扩采的多数和利益集团。支持者可以用“不能让雪怪白死”要求扩产，霜星则拒绝把伙伴的一次有限求生牺牲登记成无限开采的启动资本。她凭制度职位、联签权限和劳动者支持持续阻碍政策通过或实施，最后一次统治集团会议破裂后，其余领导者决定清除霜星并拆除这些制度刹车。
- 塔露拉以新国家最高协调者、集团意志执行界面和神圣契约债务人的三重身份亲手杀死霜星；现实政治动机与1-6神谕彼此独立地产生，最后汇合为同一行动。旧草稿的凿头与爱国者食人接口仍废止，不能因政治重构而回流。
- 复活后的阿丽娜从未与她重逢，也从未以阿丽娜身份向她显现或回应。她临死会看见“神圣崇高的灵”，但只把祂认作神，不会认成阿丽娜，也不会完成对“莉夏”这一具体人物身份的辨认。神站在那里不言不语；这与阿丽娜只向塔露拉开放人物交互通道并不冲突。
- 她死后，新国家可以保留其“最初矿业方案提出者”的名字，却删除她规定的限量、期限、矿图红线与现场执行刹车，把她的政治遗产转为无限扩张的起点。

## 关系

- 阿丽娜：宗教启蒙与问题提出者。
- 塔露拉：革命同伴，后来成为其交易代价。
- 塔露拉：除革命同伴和交易代价外，也是矿业政策关系。塔露拉最初因她的经验接受临时开采，后来必须独自决定是否把该例外永久化、国家化。
- 爱国者：父女关系。
- 莉夏／父：所信之神最终以只被她认作神的神圣灵体显现，却拒绝说话或施救。生前阿丽娜曾接受她的宗教启蒙；复活后的阿丽娜只与塔露拉交互，霜星不再与她重逢、对话、触碰或互相看见。

## 核心画面

- 向阿丽娜讲飞鸟与麻雀经文。
- 实体黑签已经确认保留：1-5先说明她因抽到黑签而起事，晚饭后再由她把“那支漆黑的木签”交给前往矿区的塔露拉。黑签由强迫下井凭证第一次变为矿工社会的识别／通行凭证，后续还可进入自愿报名与安全限额的功能反转。
- 被清空或倒置用途的黑签箱：从强迫某人下井的抽签装置变成自愿报名／安全限额装置；报名多于防护名额时，反而抽出暂时不得下井的人，撤回报名不受惩罚。
- 第一次交易成功后回到矿站的粮药列车，以及没有任何雪怪名字的返程人员栏。
- 临死祷告时看见“神圣崇高的灵”；她只认出神，没有认出阿丽娜。神在场却沉默，她因此喊出“我的神，我的神！你为什么离弃我？”；叙述层“莉夏是祂，阿丽娜也是祂”不是霜星的辨认。
- 冻结死亡；是否仍凿下头颅待定，不能只为保留身体奇观而执行。

## 待确认

- 她在1-4.5与1-5之间停雪三日的空隙带雪怪小队抵达；现行1-5用压缩履历说明她原是东方矿工、因黑签起事，并持塔露拉此前捎来的会合信找到村庄、相约革命。旧矿线在晚饭中出现，实体黑签随后交到塔露拉手里；不再要求把圣经、黑签和地图一次性并置成开场设定画面。
- 她为临时矿业方案规定哪些不能越过的边界；产量上限、工人自治、停止日期和矿图界线均为助手候选，尚未确认。
- 她在战争中、旧root崩溃和战后重建中分别怎样实际维护限采边界；不能等到卷末才突然恢复为政策反对者。
- 新共同体最高执行机构、霜星的正式职位及否决／联签权尚待命名和细化；不得再给她添加雪怪控制节点。
- 雪怪全灭的具体表层冲突仍待细化。现行推荐是哥伦比亚秘密代理买方与边境铁路警卫、反走私机关、矿业财团或敌对派系信息不共享；塔露拉选择按约带走物资、保住买方和线路，让雪怪承担断后。结果已经确认，不再待定。
- 作者本轮提出：她可凭矿场经历向塔露拉指出一条既有源石走私线路，成为塔露拉主动联系哥伦比亚的契机。她究竟知道的是矿工换取药品的小路、废弃铁路支线还是成熟中间人网络，尚未确认；优先保持她只提供经验与有限求生方案，不让她直接替塔露拉完成国家级外交选择。
