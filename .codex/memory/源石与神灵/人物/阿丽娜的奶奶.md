# 阿丽娜的奶奶

## 身份与别名

- 阿丽娜的祖母。

## 当前叙事功能

- 1-4.5村庄制度寓言中的上一代人。
- 她签署申请、接受自我消除，表现制度如何把对个体的毁灭内化为自然、成熟和责任。

## 人物关系

- 阿丽娜将奶奶的选择解释为对后辈的爱。
- 塔露拉知道奶奶并非单纯为了阿丽娜，而是已经被社会制度规训；面对阿丽娜的自我安慰，塔露拉仍以“一定是的”确认这种解释。

## 核心画面与隐喻

- “血长熟了要去脑袋”：对应红细胞成熟后去核。
- 签署申请并自我消除：生理成熟、社会规训与代际牺牲被合并为同一套自然化叙事。

## 禁止误读与负面样本

- 不把她的自我消除直接确认为出于对阿丽娜的爱。
- 也不必把她写成清醒认识制度后主动反抗或主动殉道的人。

## 待确认

- 她是否拥有超出阿丽娜回忆之外的独立叙述。
