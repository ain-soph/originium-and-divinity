# 阿丽娜的奶奶

## 身份与别名

- 阿丽娜的祖母。

## 当前叙事功能

- 现有1-5村庄制度寓言中的上一代人。塔露拉提出带她和阿丽娜离开乌萨斯，她以自己是拖累、国家需要更换血液为由拒绝，当面签字；之后阿丽娜发现她在房梁下上吊，卫兵外翻裹尸袋并插回收旗。
- 她签署申请、接受自我消除，表现制度如何把对个体的毁灭内化为自然、成熟和责任。

## 人物关系

- 阿丽娜将奶奶的选择解释为对后辈的爱。
- 塔露拉知道奶奶并非单纯为了阿丽娜，而是已经被社会制度规训；面对阿丽娜的自我安慰，塔露拉仍以“一定是的”确认这种解释。

## 核心画面与隐喻

- 奶奶说长生老爷是国家心脏、普通人是血；“血长熟了是要去脑袋的”由阿丽娜在奶奶死后根据书本提出，不能误记为奶奶自己的台词。既有作者确认该句对应红细胞成熟去核。
- 签署申请并自我消除：生理成熟、社会规训与代际牺牲被合并为同一套自然化叙事。
