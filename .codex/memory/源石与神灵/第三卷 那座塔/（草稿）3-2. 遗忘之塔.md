# 3-2《遗忘之塔》

## 当前状态

- 世界设定、参考资料和机制提纲。

## 作者思路

- 凯尔希在512岁意识到感染者寿命上限为1023，于是探索永生。
- 三条道路：南极修建遗忘之塔；利用血族骨髓持续更换器官；把WeedGuy生命链接并封印在脊椎。
- 莉夏称她为“泰拉的女祭司，凯尔希·伊丽莎白伯爵夫人”。
- WeedGuy来自核弹实现机制：不可见、无敌、零射程，通常不能攻击；与警犬重叠后可无限发射核弹。
- 莉夏登神仪式需要凯尔希的皮毛或身体材料，具体方案待整合。

## 写作意图与思想

- 把追求永生写成跨越寿命数据类型边界的“罪”。
- 凯尔希掌握文明与医学，却把感染者、血族和世界底层单位当作续命材料。
- 遗忘之塔不是凯尔希的道路，而是她替莉夏完成的闭环设施。

## 核心画面

- 南极荒野中被诸神遗忘的高塔。
- 凯尔希脊椎内封印一个不可见的无敌单位。
- 512岁时她突然理解1023上限。
