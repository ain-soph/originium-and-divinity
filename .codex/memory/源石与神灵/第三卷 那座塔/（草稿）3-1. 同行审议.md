# 3-1《同行审议》

## 当前状态

- 大型设定与场景提纲，学术会议部分结构明确。

## 作者思路

- 全球生物医学会议在天灾异常背景下举行，凯尔希担任评审。
- 塔露拉报告活性源石因子、肿瘤抑制与感染者固定机制，指控长生种依赖感染者维持低源石环境。
- 凯尔希以感染者胚胎制造短生种转长生种的“靶向药物”报告反击；参会精英因能从中获益而迅速转向。
- 塔露拉以标准review和IRB问题揭露论文伦理，同时暗示凯尔希的报告是临时构思。
- 感染者因食物和衣服自愿捐献胚胎，塔露拉无法用抽象正义取代其现实生存收益。

## 与第一次冲击衔接的生物机制（当前工作设定）

- 源石病沿神经、血管和组织间隙生成的并非完全随机结晶，而是一套拓扑结构近乎同构的微晶格。个体病灶外观不同，负责信号放大、源石技艺与高频耦合的底层结构却相同。
- 这套结构相当于所有感染者共享的外来神经模块，也是莉夏预埋后门的物质基础。3-1的论文数据可提前暴露“不同物种、不同病程的结晶却存在异常一致的局部结构”，但此时研究者只把它解释为源石自组装规律。
- 微晶格同时接入感觉—认知回路并具有直接电磁耦合能力，因此3-3可以从两个 attack vector 命中同一后门：极光对抗图像经视觉通路输入，编码电磁波绕过感官直接输入。
- 罗德岛抑制药物除控制病灶外，还会扰乱微晶格的导电性、共振频率和相位同步。这是药物能在3-3阻断定向通用触发码的原因。
- 若要埋伏笔，可让凯尔希坚持删除或降格讨论“跨物种晶格同构性”，因为一旦承认它，就等于承认源石病更像被部署的接口而非自然疾病。

## 写作意图与思想

- 学术真理、伦理审查和阶级利益可以在形式完备的情况下共同完成暴力。
- 775个感染者胚胎实验拥有可查的IRB批准号，是全书“制度反对的不是残酷，而是未经制度批准的残酷”的科研版本：伦理批准使实验形式合法、可发表、可致敬，却不自动使牺牲正当，也不能替研究者承担生命代价。
- 长生种并非只靠阴谋统治；短生种精英与贫困感染者都可能因各自收益参与体系。
- 塔露拉再次面对“受压迫者为什么不接受她的解放”。

## 核心画面

- 凯尔希给论文打3分borderline。
- 一篇开篇作异常完整，像作者先知道答案再设计实验。
- 凯尔希报告结束后掌声雷动，塔露拉仍给出strong reject。
- 775个感染者胚胎被压缩为论文数据点与IRB编号。
- 莉夏听见“甲胎蛋白所以吃胚胎”的结论后讶然失笑。
