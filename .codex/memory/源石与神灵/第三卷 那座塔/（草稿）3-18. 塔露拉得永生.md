# 3-18《塔露拉得永生》

## 当前状态

- 完整人物结局提纲，身体症状和关键对话较明确。

## 作者思路

- 莉夏登神后所有感染者源石结晶盛开，塔露拉进入死亡倒计时。
- 她反复经历心悸、窒息、疼痛与濒死恐慌，逐渐失去对革命和感染者事务的兴趣。
- 病痛最终把她压缩成纯粹求生欲。
- 塔露拉以富家子求永生的经文向莉夏请求；莉夏列举她认识的一切正在消亡，塔露拉仍坚持索取永生。
- 莉夏让她看见自己过去批判凯尔希和长生种的样子，塔露拉接受羞耻，因为临死时脸面已不重要。

## 写作意图与思想

- 完成塔露拉对长生种批判的自我反转：“我憎恨长生种，只因为长生种不是我。”
- 不把求生欲轻易道德化；让长期身体折磨真实压垮革命者。
- 神严格应允“永生”，但永生含义将在后日谈显露为无法退出叙事。

## 核心画面

- 塔露拉每天三次在床上蜷缩，等待濒死感退去。
- 她佝偻、黑眼圈、走几步便喘，思想被求生欲清空。
- 她跪到莉夏面前引用经文索求永生。
- 莉夏逐一列举已经死去的人，塔露拉仍回答“即使如此”。

## 待处理

- 症状描写应有节制，避免重复削弱最终跪求的重量。
- 明确莉夏应约时是否给出任何可被误解的具体承诺。
