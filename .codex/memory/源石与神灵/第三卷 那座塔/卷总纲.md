# 第三卷《那座塔》卷总纲

## 当前状态

- 3-1和3-19材料最充足。
- 3-2、3-5、3-8至3-10、3-18已有明确结构。
- 其余多为核心场面或机制提纲。

## 作者思路与故事设计

- 通过学术会议揭示源石、长生种、感染者、医学与阶级统治的共同机制。
- 凯尔希为逃避1024岁的边界探索修塔、换血换器官和生命链接。
- 莉夏利用源石后门发动第一次冲击；罗德岛因预先研究抑制药物保有部分抵抗。
- 第一次冲击的当前工作机制：莉夏多年前引发并瞄准泰拉的伽马射线暴在此刻抵达，以约十秒的复杂时间—能谱结构发动多向量攻击。大气源石尘埃显影出的极光噪声是视觉 adversarial image，编码电磁波则直接命中源石晶格的 backdoor；两条路径可独立触发并共同锁存控制状态。
- 臭氧异常是辐射造成的结果、紫外二次辐射的显影窗口和事件留下的伤口，不是阻挡高能粒子的物理闸门。世界把伤口误认成入口。真正传播依靠天文辐射、源石—电离层耦合及全球源石设施的中继。
- 旧稿曾让阿丽娜作为可见、可被杀死的诱饵吸引反抗者；该方案因“复活后的阿丽娜只与塔露拉交互”而失效，反抗者不能看见、听见、攻击或验证她。真正的登神工程仍在南极遗忘之塔完成；用于误导主力的替代目标或假情报机制待重新设计，不能直接把阿丽娜换名后当作已确认方案。
- 后日谈中阿丽娜认领记忆、暴行与神位的旧解释已经失效：作者最新明确，生前有限阿丽娜是人，但1-6后站回阿丽娜位置上的主体就是神／父，因此她自称神属于事实。塔露拉若否认“你不是祂”，只能先作为人物判断；该段客观叙述、记忆归属及其与生前救世主欲望的连续性需要另行重审。
- 复活后的阿丽娜在第三卷仍只与塔露拉交互。3-5中两人的封闭谈话与接吻可保留，但外部反抗者不能以她为可感知目标；3-19中照片走出的阿丽娜也只能进入塔露拉的感知，医疗人员不得见证、回应或验证她。
- 凯尔希年龄溢出使世界发布“杀死凯尔希”任务；莉夏反而保护她，让世界任务无法结算并进入调试状态。
- 卷名“那座塔”所指的是巴别塔，即“语言之塔”。塔不只汇合高度、工程和管理员权限，也把语言本身显露为世界的可执行接口：拥有权限并不自动等于能够用正确语言调用权限。
- 3-9塔顶的莉夏与凯尔希拥有相同的管理员权限，但凯尔希不懂神的语言，也不懂以调试命令向世界发言；莉夏则能够说出世界可执行的命令。因此二人是“同权不同能”：差异不来自莉夏暗中持有更高权限，而来自同一权限能否经语言转化为有效操作。凯尔希可以拥有整个世界的admin特权，却连`hello world`都无法正确输出。
- external角色与管理员权限完成自举环节；登神仪式不是制造神，而是闭合神始终存在的时间结构。
- 第三卷最终目的按“集成测试”回收第一卷第二次握手暗埋的连接协议。1-6中塔露拉问“约定吗？”近似SYN，神从雾中伸手近似SYN-ACK，塔露拉接住并共同完成握手压缩最终ACK；“约定同步了”提示连接已建立，“约定了”是成立后的神圣确认。第三卷应让这条连接实际参与状态同步、验证或闭合，而不是只补一句TCP术语说明。
- 塔露拉临死索求永生；后日谈在医院和近似官方世界线中回收第一章。

## 写作意图

- 把个人契约和群众信仰最终提升为世界底层规则与权限问题。
- 以巴别塔／语言之塔区分权限与能力：权限只回答“是否获准执行”，神的语言决定角色能否组成并提交一条世界能够理解的命令；凯尔希由此在形式上与莉夏同权，实际却不能。
- 让前两卷的约定、握手和接口在第三卷显露为同一系统的连接建立、状态同步与最终集成测试；技术层应在重读时可验证，初读仍能只按契约理解。
- 建立非对称身份规则：神是塔露拉、阿丽娜和莉夏，却不因采用、包含或占有某个人物身份，就允许该人物反向成为或占有神。
- 让凯尔希、能天使和塔露拉分别面对“是否愿意为自己的叙事承担死亡”。
- 让阿丽娜与凯尔希形成反向对照：二人都需要自己是救世主；阿丽娜以牺牲自己取得非凡，凯尔希以拯救世界为由证明自己不可牺牲。
- 将医院、科研伦理、源石污染、世界程序和宗教献祭写成同一套处理生命的结构。
- 把“制度反对的不是残酷，而是未经制度批准的残酷”推进到科研与程序层：IRB批准号、同行审议和管理员权限都能使残酷获得可执行资格，却不能替行动者理解生命重量或承担代价。

## 核心画面

- 全球医学会议上塔露拉以同行审议质问凯尔希。
- 所有源石携带者被后门统一控制。
- 天空出现无法被正常观看和理解的极光噪点；可见色带既是信号的低维投影，也是能够独立攻击感染者视觉—认知通路的对抗图像。
- 塔露拉亲吻阿丽娜，把亲吻变成识别莉夏的信号。
- WeedGuy与警犬重叠，无限核弹使世界卡死。
- 1024岁生日到来，World.exe停止响应。
- 莉夏保护全世界都在追杀的凯尔希。
- 塔顶同一管理员接口前，莉夏能以神的语言调试世界，凯尔希拥有同级权限却不会输出`hello world`；“同权不同能”由语言而非权限差额形成。
- 能天使拦在莫斯提马面前宣布自己将在此成为英雄。
- 角、脑、眼献祭，太阳圆盘升起。
- 阿米娅庆功讲话转化为对莉夏的赞颂。
- 病床上的塔露拉发现能天使少了一只眼。
