# 3-12《罪与罚》

## 当前状态

- 文学、历史和情节主题笔记。

## 作者思路

- 以《罪与罚》“凡人跨越界限成为非凡者”的理论解释莉夏升华，也审判凯尔希、塔露拉等自认能凌驾法律的人。
- Raskolnikov名字关联分裂者、异教和蔑视上帝者；整合运动“Reunion”则意为重新统一。
- 凯尔希或阿米娅宣称想成为凯撒、拿破仑，莉夏以“凯撒的物归凯撒，神的物归神”回应。
- 时间冻结准备，博士希望理论正确，远方巴别塔／遗忘之塔完成。

## 写作意图与思想

- 贯穿全书追问：人物杀人或越界的真正动机是否真是更高目的，还是想证明自己属于非凡者。
- “罪”与跨越界限、数值越界、宗教分裂建立同词异义网络。
- 莉夏与普通越界者不同：她不是凡人靠仪式成为神，而是只有神才能闭合仪式。
