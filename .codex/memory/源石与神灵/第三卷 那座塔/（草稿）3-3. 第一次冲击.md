# 3-3《第一次冲击》

## 当前状态

- 核心事件提纲。

## 作者思路

- 莉夏激活源石后门，所有源石携带者被统一心灵控制。
- 心灵控制由莉夏多年前引发、此刻才抵达泰拉的天体高能辐射触发。
- 心灵控制采用多个 attack vector，而不是一把缺一不可的双重钥匙：带噪的极光对抗图像攻击视觉—认知通道，编码电磁波直接触发源石晶格后门；两条路径可分别命中，也可叠加。
- 该信号是所有感染者共享的 universal trigger，概念来源于 CNN 安全研究中的通用对抗扰动与后门触发器。
- 罗德岛因早已发现源石病真相并研制抑制药物，部分成员不受控制。
- 意志或防护不足的干员反叛；幽灵鲨杀死斯卡蒂。

## 心灵控制机制（当前工作设定）

### 天文信号

- 当前建议采用一次**被精确瞄准泰拉的伽马射线暴**，而不是普通太阳风；磁星巨型耀发可作为相近的备选天体事件。
- 莉夏在许多年前令一颗遥远天体发生伽马射线暴。事件与泰拉相隔若干光年，窄束辐射按光速延迟至“第一次冲击”当天抵达。它不是莉夏当场施法，而是一道早已发出、现在才执行的命令。
- 整次主要照射只持续约十秒。伽马射线暴自身复杂的时间—能谱结构负责携带高维触发码：不同能段的强度、尖峰间隔与相位关系共同构成输入，不需要把自然语言逐字编码进电磁波。
- 十秒结束后，感染者不会自动恢复。触发码使体内源石微晶格发生一次锁存式相变，进入能够自我维持的目标状态；天文辐射只是输入，持续控制的是已经改变状态的源石。
- 这也可作为登神时间闭环的低层回声：莉夏之所以能在过去精确安排今日信号，是因为今日的神已经知道它必须抵达。

### 臭氧空洞与极光

- **臭氧层不能作为阻挡高能粒子的门。**它主要吸收紫外线；伽马射线、硬 X 射线和高能带电粒子的传播主要受整层大气与磁层影响。
- 因此保留“信号从臭氧空洞落下”的民间观察，但将真实因果反转：并不是空洞放进了伽马射线暴，而是伽马射线暴电离、离解大气并制造了后续的臭氧损耗。人们把信号留下的伤口误认成信号进入的门。
- 伽马射线暴在含源石尘埃的电离层中产生二次辐射与异常气辉；后续臭氧异常让其中的紫外成分更容易到达地表，也是天空图案最清晰的“显影区”。
- 极光不是普通极光，也不只是无害的可见投影。电离层中的源石尘埃把脉冲码显影成噪点、断裂色带与重复图形；这幅天空图像本身就是一个定向通用对抗样本。
- 感染者不抬头、不处于晴夜，仍可能被电磁 attack vector 命中；看见极光则意味着视觉 attack vector 也已进入。可见图像与不可见信号是两条攻击路径，不是同一信号的必要两部分。
- 如需继续强调“臭氧层空洞”，可将它写成科学家最初认定的入口，随后由罗德岛指出：空洞只是信号留下的伤口，不是信号经过的门。

### 多 attack vector 的 universal trigger

- 感染并非只让每个人长出不同的矿物。源石病会沿神经系统形成一套结构近乎同构的微晶格，相当于在不同大脑上附加了同一种外来模型。
- 这套晶格平时参与源石技艺、能量交换和神经信号放大，同时保留莉夏预埋的后门。人类的大脑各不相同，但后门结构相同，因此触发器可以“通用”。
- **视觉 attack vector：**极光的空间纹理、颜色关系与时间变化构成 adversarial image。图像先经过正常视网膜与视觉通路，再利用源石病对感觉—认知回路造成的共同偏置，把不同视觉输入推向同一个高层表征。
- **电磁 attack vector：**伽马射线暴及源石网络转写出的编码电磁波，不经过眼睛，直接以频谱、相位、脉冲间隔和偏振等结构驱动源石微晶格，命中预埋后门。
- 两条路径的输入形式不同，攻击面也不同，但输出目标相同：把任意感染者的当下感觉、记忆和情绪推向同一个稳定状态——**Be one with Risa**。
- 视觉路径更接近 targeted universal adversarial perturbation；电磁路径更接近预装模型的 backdoor trigger。整个第一次冲击是二者组成的多向量攻击。
- 两条路径可以各自触发锁存，因此闭眼、室内或视觉遮蔽不能保证安全，单纯电磁屏蔽也不能保证安全。同时命中时，晶格更快进入更深、更难逆转的稳定吸引子。
- 触发后不必抹除记忆与技能。感染者仍知道自己是谁、认得亲友、保有战斗习惯，却把莉夏的目标体验为自己的目标；这比变成木偶更适合熟人互杀。
- 普通极光、普通图像和普通电磁噪声不会误触发，因为每条攻击向量都必须匹配感染者微晶格中预设的高维特征；安全性来自触发码的特异性，而不是要求两条路径同时出现。
- 第一次冲击只需要十秒输入，是因为后门并不持续计算莉夏的命令，只在第一次匹配时把晶格写入一个稳定吸引子。此后每个人都由自己的源石维持控制。

### 罗德岛药物与个体差异

- 罗德岛药物的真正作用不是增强意志，而是改变源石微晶格的导电性、共振频率与相位同步，使相同触发码无法在体内完成一致解码。
- 药物防御的是两条路径共同依赖的源石解码层，因此既能削弱视觉对抗图像造成的异常映射，也能削弱电磁后门信号的直接共振。眼罩、地下掩体、滤光设备或电磁屏蔽只能防其中一条路径。
- 对已触发者，药物还必须破坏锁存后的晶格相态，才能使其退出控制；“预防药”和“逆转药”可以因此成为两种不同、疗效悬殊的制剂。
- 药量、服药时间、感染程度和结晶位置决定保护是否完整。所谓“意志不坚定”可以保留为人物的误解；若需要意志发挥作用，只让它决定半触发状态下能抵抗多久，不让意志本身凌驾于机制。
- 完全阻断者保持清醒；部分阻断者意识清醒但目标与动作被篡改；未阻断者保留人格、记忆和技能，却把反叛当成自己刚刚作出的决定。
- 幽灵鲨的特殊生理、长期药物史与深海因素可使她成为最危险的“部分阻断”个体：她足够清醒，因而能准确杀死斯卡蒂；也不够清醒，因而把杀戮理解为自己的选择。

### 全球同步

- 第一、二卷对源石的开采、贸易、医疗使用和基础设施铺设，实际上把同一种晶体扩散成覆盖世界的接收与中继网络。
- 天文脉冲首先唤醒高空源石尘埃与大型源石设施，再由地表网络完成全球转发。世界各地不是严格物理意义上的绝对同时，而是在数秒内依次“刷漆”；人物感受上仍是同一瞬间。
- 这使第一次冲击成为前两卷历史的因果回收：人类亲手开采、运输并接入生活的能源系统，最终显露为神的行星级神经系统。

## 写作意图与思想

- 源石病从身体疾病显露为神预埋在众生中的控制接口。
- 罗德岛“制药公司”真正药物功能与世界阴谋发生回收。
- “祝你在梦中也能保持清醒”在控制与反叛中转为反讽。
- 控制并非神隔空压倒无数人的意志，而是众生早已把同一个错误结构接进身体，只等待宇宙按时发送输入。
- 天空中的“神迹”只是信号的可见残影；真正的命令存在于感染者无法感知、却能被体内源石读取的维度。
- 天空中的神迹同时也是攻击面：它既是不可见电磁命令的可见残影，又是能够独立进入视觉系统的对抗图像。
- 借鉴伽马射线暴灭绝假说的时间结构：灾难的输入只有几秒，真正的后果却在输入结束后才长期展开。
- 臭氧空洞承担一次因果误认：世界把伤口当成入口，把结果当成原因。

## 核心画面

- 全世界源石携带者在同一瞬间被刷成同一阵营。
- 有人仰望极光后转身，有人在没有窗户的房间里同样转身；两个场面证明攻击并不只经过眼睛。
- 罗德岛内部熟悉的人突然转身互相杀戮。
- 幽灵鲨杀死斯卡蒂。

## 研究依据与科幻边界

- 2004 年提出的“伽马射线暴触发奥陶纪末大灭绝”假说，设想约十秒的脉冲输入通过破坏臭氧层、增加地表 UVB 并扰动气候造成长期生态后果。
- 相应大气模型中，一次持续十秒、能量通量为 100 kJ/m² 的银河系伽马射线暴可造成全球平均约 35% 的臭氧损耗，部分纬度约 55%，显著损耗持续五年以上。该结果证明的是机制可行性，不是奥陶纪确实发生过伽马射线暴的直接证据。
- 该灭绝假说目前缺乏能够唯一指向伽马射线暴的地质证据，也不是奥陶纪末大灭绝的主流定论；较新的综述更重视冰期、栖息地丧失、海洋变化与火山活动。小说借用的是“几秒输入—多年后果”的因果模型，不需要宣称现实假说已获证实。
- 现实中的磁星巨型耀发同样可造成电离层扰动，并具有“短促尖峰＋周期脉冲尾”的结构；若后续更需要规则而重复的载波，可再改回磁星方案。
- 高能光子或太阳质子事件能够电离、离解中层大气，生成 NOx/HOx 并破坏臭氧；臭氧损耗可持续数周至数年。但“臭氧空洞让高能粒子穿透”不符合现实物理。
- 现实机器学习中，后门模型可在干净输入下正常工作，在预设触发图案出现时统一转向攻击者指定输出；物理可实现、位置相对不敏感的通用图案也已有研究。
- “源石尘埃把伽马射线暴转写为全球极光码”“人体源石微晶格直接耦合神经目标函数”属于本作科幻设定，不声称为现实神经科学。
