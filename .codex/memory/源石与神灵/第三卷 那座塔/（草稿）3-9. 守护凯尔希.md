# 3-9《守护凯尔希》

## 当前状态

- 反转机制明确的章节提纲。

## 作者思路

- 系统捕获`Kaltsit.age == 1024`异常，向全世界发布24小时内杀死凯尔希的强制任务。
- 凯尔希此前领导众人反抗莉夏，此刻却成为所有人的目标。
- 莉夏告诉凯尔希：只要她选择死，莉夏的计划便失败，战争即可胜利；凯尔希拒绝死亡。
- 莉夏反而保护凯尔希，让任务失败并使世界进程挂起。
- 两人在塔顶同权不同能：凯尔希拥有管理员权限，却不会使用调试命令。

## 写作意图与思想

- 检验凯尔希是否愿意亲自承担她长期要求别人承担的牺牲。
- 区分拥有权力与理解权力；凯尔希精通政治、医学和选举，却不会输出`hello world`。
- 神保护敌人不是仁慈，而是为了让世界无法结算。

## 核心画面

- 全球所有人视野中出现同一猎杀任务与倒计时。
- 莉夏站到凯尔希身前，抵挡原本反抗自己的世界。
- 塔顶命令行前，凯尔希拥有admin却不会操作。
- 莉夏建议：“也许你应该--help，猞猁女士。”

## 伏笔与回收

- 任务失败进入3-11管理员调试会话。
- 凯尔希拒死与3-10能天使主动赴死形成对照。
