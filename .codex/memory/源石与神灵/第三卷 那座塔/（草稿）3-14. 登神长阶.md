# 3-14《登神长阶》

## 当前状态

- 仪式核心提纲。

## 作者思路

- 莉夏使用塔露拉之角、凯尔希之脑、能天使之眼完成献祭。
- 太阳圆盘从塔顶升起，肃清黑暗。
- 红色传送门出现在云顶，融合《暗黑破坏神2》和相关飞升仪式意象。

## 已确认的仪式本质

- 仪式赋予神权，但只有神权才能完成仪式。
- 莉夏不是由仪式从非神升级成神；只有始终是神的莉夏能够完成这场登神仪式。
- 仪式是神自我存在的闭环条件和身份验证，不存在第一位普通执行者。

## 核心画面

- 龙角、猞猁之脑和独眼天使之眼成为三件祭品。
- 塔顶太阳圆盘升起。
- 登神长阶通往云顶红门。

## 待处理

- 三件祭品各自的思想含义与取得过程需要在前文充分建立。
- 仪式现场应让世人误判“莉夏正在成神”，同时留下只有重读才能理解的闭环证据。
